# Campus QuickAssist – AI Interaction Log

## Activity A: Planning

### What did I ask AI?

I asked AI to identify the requirements, divide the application into smaller modules, suggest suitable methods, identify possible edge cases, and prepare a step-by-step execution flow.

### What did I learn?

I learned how to plan a Java application systematically by dividing it into smaller and manageable modules. I understood the importance of identifying user requirements, selecting appropriate methods, handling different situations, and designing a proper execution flow before starting the coding process.

## Activity B: Code Review

### What did I ask AI?

I asked AI to review my Java code for logical errors, code duplication, method responsibilities, input validation, boundary conditions, and readability.

### What did I learn?

I learned the importance of writing clean, organized, and reusable code. I understood how code duplication can be reduced by using methods and how input validation helps prevent incorrect entries. I also learned to improve code readability and identify logical mistakes.

## Activity C: Debugging

### What did I ask AI?

I asked AI to identify situations where the application could produce incorrect results or behave unexpectedly.

### What did I learn?

I learned how to identify and fix errors by testing different inputs and situations. I understood the importance of checking boundary conditions, handling invalid inputs, and testing the application after making corrections. This improved my debugging and problem-solving skills.

## Conclusion

AI helped me understand the development process of my Campus QuickAssist Java application. It guided me in planning, reviewing code, identifying errors, and improving program structure. I learned that AI can be a useful learning assistant, but testing and understanding the code myself are equally important.
