# Campus QuickAssist

## Project Description

Campus QuickAssist is a console-based Java application that helps
students register their academic, technical, administrative, and
other support requests.

The application collects student information, validates inputs,
calculates ticket priority, and displays a ticket summary.

## Features

- Register student support requests
- Select a problem category
- Validate student information
- Calculate HIGH, MEDIUM, or LOW priority
- Display ticket summaries
- Register multiple requests
- View priority guidelines

## Technology Used

- Java 25
- Scanner
- Console-based application

## How to Run

1. Install Java 25.
2. Open a terminal in the project folder.
3. Compile the program:

   javac Main.java

4. Run the program:

   java Main
